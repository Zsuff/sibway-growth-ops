# Content & SEO Writing Rules

Джерело: Google Search Central — SEO Starter Guide + SEO Guide for
Web Developers (офіційна документація Google, 19.09.2026).

## 1. Структура сторінки
- Унікальний, описовий `<title>` для кожної сторінки (без дублювання
  між мовними версіями чи схожими сторінками)
- Унікальний meta description (150-160 символів), що реально описує
  вміст сторінки
- Короткі абзаци з заголовками H2/H3 для навігації читачем
- Описові URL (`/uk/services/import-poland`, не `/uk/page-1`) — ключові
  слова в URL мають мінімальний вплив на ранжування, не самоціль

## 2. Унікальність і корисність контенту — головне правило
- Ніколи не копіювати текст із сайтів конкурентів — використовувати
  лише як референс структури
- Контент пишеться для реального відвідувача, не "під пошукову систему"
- Регулярно оновлювати застарілий контент або прибирати його

## 3. Пошукові наміри
- Враховувати, що одна тема має різні формулювання запиту в різних
  аудиторій (наприклад "вантажні перевезення" vs "доставка товару") —
  Google розуміє синоніми й контекст, не потрібно вгадувати кожен варіант

## 4. Внутрішня перелінковка
- Кожна сторінка досяжна щонайменше одним внутрішнім посиланням
- Анкор-текст посилання описує сторінку призначення, не "тут"/"детальніше"
- Зовнішні посилання без повної довіри — з атрибутом rel="nofollow"

## 5. Зображення
- Описовий alt-атрибут для кожного зображення
- Зображення розміщувати біля релевантного тексту

## 6. Технічні правила
- Дублі контенту — не порушення, але вирішувати через canonical/301-редирект
- Перевіряти через GSC URL Inspection, що Google бачить сторінку так само,
  як користувач (особливо для JS-контенту)
- Підтримувати sitemap.xml в актуальному стані з кожною новою сторінкою

## 7. Чого уникати (поширені міфи)
- ❌ Meta keywords — Google їх не використовує
- ❌ Keyword stuffing — проти spam-політики Google
- ❌ Гонитва за "ідеальною" довжиною тексту чи кількістю заголовків
- ❌ E-E-A-T як прямий ранжуючий фактор (хоча експертність тексту
  все одно важлива для читача)
- ❌ Штучний порядок H1→H2→H3 заради алгоритму (важливо для зручності
  читання, не для ранжування)

## 8. Просування поза сайтом
- Найефективніший довгостроковий канал — органічні рекомендації/сарафанне
  радіо (підтверджено власним досвідом Sibway — основне джерело клієнтів
  зараз саме повторні звернення)
- Соцмережі й галузеві згадки природно ведуть до посилань, які Google
  цінує більше за штучні методи

---
Ці правила застосовуються при написанні всіх майбутніх SEO-сторінок
(вкладка 05_SEO_Content_Map) і блог-контенту.
